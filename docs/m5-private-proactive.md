# M5：私聊主动与想法生命周期

从留档 m5 增量合入，保留 M3/M4 与原文上下文实现。未部署。

## 默认行为

私聊每天最多 6 次主动唤醒、最小间隔 90 分钟、23–8 点硬阻断；有未读、会话繁忙、距上次唤醒不足 30 分钟、对方未回应的主动轮次达到 3 次时阻断。仍保留随机机会判定。定时想法遵循同一配额与限制，不单独绕过。群聊沿用旧主动调度。

额度在共享唤醒入口预留，明确投递失败时回滚；已入队唤醒保守占用额度。额度衡量主动唤醒次数，不是气泡数，不对单次气泡数额外设限。连续未回应按实际主动发言轮次累计，同轮多气泡只记一次；对方来信/拍一拍清零。

想法包含 id/status/notBefore/expiresAt/attempts/kind/priority。展示多个想法时逐项处理，成功发送的文本与想法重叠则消费；发送无关内容仍增加未消费想法的尝试次数，默认 3 次后丢弃。到期想法进入 dropped 历史。qq_thought_use/drop 可显式处理，过期或已处理 id 不再接受。

到期计时器恢复已到期但仍有效的想法；长延迟按 Node 定时器上限分段检查。每次真正执行时重新检查模式、暂停、白名单与开关。零间隔、零冷却、午夜 0 点配置不再被默认值覆盖。

## 验证

npm run test:proactive 包含纯规则和隔离 bridge 生命周期测试。回归 M3 reset、M4 distill、上下文和 preset 契约。测试没有真实 QQ 发送。

自动消费使用词元重叠，属于启发式，可能误判；需要精确确认时使用显式工具。真实模型是否恰当选题、真实时间长周期行为仍需部署观察。
